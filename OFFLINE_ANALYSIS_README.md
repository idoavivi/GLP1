# Offline Analysis Guide

## What You Downloaded

### Data Files (RData)
- **`glp1_cleaned_data.RData`** - Main cleaned dataset (REQUIRED)
  - Contains: obesity cohort, cleaned weight, activity, BMI data
  - Size: ~50-200 MB

- **`weight_diagnostics.RData`** - Diagnostic analysis results (optional)
- **`period_analysis_optimized_results.RData`** - Analysis results (optional, regenerated by scripts)

### Analysis Scripts (R)
- **`diagnose_weight_patterns.R`** - Weight loss diagnostic analysis
- **`investigate_low_baseline_weights.R`** - Investigates <100kg patients
- **`sensitivity_analysis_quality_cohort.R`** - High-quality cohort analysis
- **`period_analysis_optimized.R`** - Main period-based analysis
- **`period_visualizations.R`** - Creates publication figures

### Reference
- **`comprehensive_data_cleaning.R`** - Data cleaning pipeline (reference only, requires All of Us data)

## Setup on Your Local Machine

### 1. Install R and RStudio (if not already installed)
- Download R: https://cran.r-project.org/
- Download RStudio: https://www.rstudio.com/products/rstudio/download/

### 2. Install Required Packages

Open RStudio and run:

```r
# Install tidyverse (includes dplyr, ggplot2, tidyr, etc.)
install.packages("tidyverse")

# Install mixed effects packages (for period_analysis_optimized.R)
install.packages("lme4")
install.packages("lmerTest")

# Install patchwork (for visualizations)
install.packages("patchwork")
```

### 3. Set Working Directory

In RStudio:
```r
setwd("/path/to/your/downloaded/files")
```

Or use: **Session → Set Working Directory → Choose Directory**

## Running the Analyses

### Quick Start (Recommended Order)

```r
# 1. Check data is loaded properly
file.exists("glp1_cleaned_data.RData")  # Should return TRUE

# 2. Run diagnostic analysis (5-10 minutes)
source("diagnose_weight_patterns.R")

# 3. Investigate low baseline weights (2-3 minutes)
source("investigate_low_baseline_weights.R")

# 4. Run sensitivity analysis (5-10 minutes)
source("sensitivity_analysis_quality_cohort.R")

# 5. (Optional) Run full period analysis (15-20 minutes)
source("period_analysis_optimized.R")

# 6. (Optional) Create visualizations (requires step 5)
source("period_visualizations.R")
```

### What Each Script Does

#### 1. `diagnose_weight_patterns.R`
**Output:**
- Weight change distribution by period
- Baseline weight vs loss correlation
- Treatment persistence analysis
- Responder vs non-responder rates
- Measurement frequency analysis

**Creates:** `weight_diagnostics.RData`

**Key Findings:**
- Why average weight loss is lower than expected
- Role of non-responders and poor adherence
- Impact of measurement frequency

---

#### 2. `investigate_low_baseline_weights.R`
**Output:**
- BMI verification for patients <100 kg
- Calculated height distribution
- Inclusion reason analysis
- List of patients to potentially exclude

**Creates:** `low_weight_investigation.RData`

**Key Findings:**
- Identifies impossible cases (BMI <30 in obesity cohort)
- Flags very short patients requiring verification
- Recommends exclusions for data quality

---

#### 3. `sensitivity_analysis_quality_cohort.R`
**Output:**
- High-quality cohort definition (4 strict criteria)
- Weight trajectories for persistent responders
- Activity changes for quality cohort
- Comparison: full vs high-quality cohort

**Creates:** `sensitivity_analysis_results.RData`

**Key Findings:**
- True treatment effect in adherent responders
- Reduced heterogeneity (lower SD)
- Clearer activity-weight relationships

**Expected Results:**
```
FULL COHORT:              HIGH-QUALITY COHORT:
  Mean loss: 8-9%           Mean loss: 11-13%
  SD: 7-8%                  SD: 5-6%
  N: 500-700                N: 150-250
```

---

#### 4. `period_analysis_optimized.R` (Optional - Slower)
**Output:**
- Complete period-by-period analysis
- Mixed effects models
- Statistical comparisons
- CSV tables and RData output

**Creates:**
- `period_analysis_optimized_results.RData`
- `period_analysis_optimized_table.csv`
- Multiple other CSV files

**Runtime:** 15-20 minutes

---

#### 5. `period_visualizations.R` (Requires step 4)
**Output:**
- Publication-quality figures
- Weight and activity trajectories
- Comparative plots

**Creates:** Multiple PNG/PDF figures

---

## Tips for Offline Analysis

### Memory Management
If you encounter memory issues:
```r
# Clear workspace
rm(list = ls())
gc()

# Load only what you need
load("glp1_cleaned_data.RData")
```

### Saving Your Results
```r
# After running analyses, save your workspace
save.image("my_analysis_session.RData")

# Later, restore it
load("my_analysis_session.RData")
```

### Exporting Results
```r
# Export tables to CSV
write.csv(your_results, "results.csv", row.names = FALSE)

# Export plots
ggsave("my_plot.png", width = 10, height = 6, dpi = 300)
```

## Troubleshooting

### "Cannot find file"
```r
# Check your working directory
getwd()

# List files in current directory
list.files()

# Set working directory
setwd("/correct/path/here")
```

### "Package not found"
```r
# Install missing package
install.packages("package_name")

# Load package
library(package_name)
```

### "Object not found"
Make sure you've loaded the data:
```r
load("glp1_cleaned_data.RData")

# Check what's loaded
ls()
```

## Summary of Key Questions Answered

1. **Why is weight loss lower than expected?**
   → Run `diagnose_weight_patterns.R`

2. **Are there data quality issues?**
   → Run `investigate_low_baseline_weights.R`

3. **What's the true effect in good responders?**
   → Run `sensitivity_analysis_quality_cohort.R`

4. **Full temporal analysis?**
   → Run `period_analysis_optimized.R` + `period_visualizations.R`
